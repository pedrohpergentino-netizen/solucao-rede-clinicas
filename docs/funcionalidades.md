# Funcionalidades e características

A solução proposta contará com funcionalidades voltadas
para a organização dos processos da rede de clínicas.

## Funcionalidades principais

### Agendamento

Permitir o registro e acompanhamento dos agendamentos
realizados pelos pacientes.

### Acompanhamento dos atendimentos

Permitir que os responsáveis consultem informações
relacionadas aos atendimentos.

### Comunicação

Facilitar a troca de informações entre os setores
envolvidos nos processos.

### Centralização das informações

Organizar as informações em um sistema integrado,
reduzindo a necessidade de consultar diferentes meios.

### Organização de documentos

Utilizar recursos de apoio, como o SharePoint, para
organização de determinados documentos e informações.

### Automações

Criar fluxos automatizados para tarefas repetitivas,
como notificações, atualizações e organização de
informações.

### Controle de acesso

Definir permissões de acordo com as funções dos usuários,
evitando que informações sejam acessadas por pessoas
sem autorização.

## O que será desenvolvido primeiro

A primeira etapa deve priorizar as funcionalidades
essenciais para o funcionamento da solução.

Inicialmente serão considerados o cadastro e consulta
das informações principais, o fluxo de agendamento e
o acompanhamento dos atendimentos.

Depois poderão ser adicionadas integrações e automações
para complementar o sistema.
