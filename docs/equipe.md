# Equipe e responsabilidades

O projeto foi dividido entre os integrantes de acordo
com diferentes áreas necessárias para desenvolver e
documentar a solução.

| Integrante | Função | Responsabilidade |
|---|---|---|
| Pedro | Full Stack e Automações/SharePoint | Desenvolvimento da aplicação, integrações e automações |
| Leticia | Analista de Requisitos + Gestor de Projetos | Responsável por entender o que o cliente precisa |
| George | UX/UI | Organização da experiência e interface dos usuários |
| Nicolas | Banco de Dados | Estrutura e organização dos dados |
| Thomas | Segurança/Testes | Segurança, validação e testes da solução |

## Justificativa da divisão

A divisão das funções permite que diferentes aspectos
da solução sejam trabalhados de forma organizada.

Cada integrante possui uma área principal de atuação,
mas as partes precisam ser integradas para que a solução
funcione de maneira coerente.

As responsabilidades podem ser ajustadas durante o
desenvolvimento conforme as necessidades do projeto.
