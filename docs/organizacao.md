# Organização do trabalho

A nossa equipe dividiu o projeto em diferentes responsabilidades
para facilitar o desenvolvimento da proposta.

Cada um ficou responsável por uma área, mas as
decisões principais são discutidas em conjunto.

## Organização

As atividades foram divididas de acordo com as funções
definidas para cada integrante.

Cada pessoa deve registrar sua contribuição e manter a
documentação relacionada à sua função atualizada.

## Comunicação

A comunicação entre a gente é importante para
evitar que diferentes partes do projeto sejam desenvolvidas
de maneira incompatível.

As decisões relacionadas às funcionalidades, tecnologias
e organização do projeto devem ser discutidas entre a gente.

## Decisões do projeto

Entre as principais decisões estão:

- Centralizar a documentação no GitHub
- Dividir as responsabilidades entre a gente
- Utilizar uma aplicação integrada
- Considerar automações para tarefas repetitivas
- Considerar o SharePoint para organização de documentos
  e informações
- Priorizar segurança e privacidade desde o planejamento

## Controle das atividades

O GitHub será utilizado para organizar os arquivos,
registrar alterações e acompanhar a evolução do projeto.

Cada um poderá trabalhar em sua própria branch
quando necessário e posteriormente enviar suas alterações
para a branch principal.
