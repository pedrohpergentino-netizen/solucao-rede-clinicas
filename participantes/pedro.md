Minha contribuição no projeto

Meu papel no projeto

Fiquei responsável pela parte de Full Stack e pelas automações relacionadas ao SharePoint. Vou ajudar no desenvolvimento da aplicação e também na parte de integração e automação dos processos.

Desenvolvimento Full Stack

Vou trabalhar tanto na parte visual do sistema quanto na parte interna. Também vou ajudar na criação das funcionalidades, integração com banco de dados e APIs.

Automações com SharePoint

Vou trabalhar com SharePoint e Power Automate para tentar automatizar tarefas repetitivas, como notificações, atualizações e organização de documentos.

Um exemplo seria uma informação ser registrada no sistema e, automaticamente, uma notificação ser enviada para o responsável pela próxima etapa.

Minhas responsabilidades

- Desenvolver funcionalidades;
- Trabalhar com Front-end e Back-end;
- Fazer integrações;
- Criar e testar automações;
- Trabalhar com SharePoint;
- Corrigir erros e testar o sistema.

Conhecimentos necessários

Para essa função são importantes conhecimentos de programação, desenvolvimento web, banco de dados, APIs e Git. Também será necessário aprender a utilizar o SharePoint e o Power Automate.

Como minha função ajuda no projeto

A ideia é ajudar a diminuir tarefas manuais e deixar as informações mais organizadas. O sistema pode centralizar algumas atividades e as automações podem facilitar processos que são repetitivos.

Relação com os outros integrantes

Minha parte depende do trabalho dos outros integrantes. Vou precisar das informações sobre o projeto, das decisões de interface, banco de dados e segurança para conseguir desenvolver as funcionalidades.

Segurança e privacidade

Como o projeto envolve uma clínica, é importante ter cuidado com os dados dos pacientes. As informações devem ser acessadas somente por pessoas autorizadas e as automações também precisam seguir essas regras.

Resultado esperado

Espero ajudar a criar uma solução organizada, com algumas funcionalidades automatizadas, facilitando o trabalho dos funcionários e diminuindo tarefas manuais.
